# Site institucional ATTIVO

Site estático de attivocorretora.com.br (HTML, CSS e JS puros, sem build).

- Páginas: `/`, `/seguros/`, `/sobre/`, `/contato/`, 4 páginas de seguro e 4 páginas locais de Americana.
- `/afiliados/` foi desativado e redireciona para a home.
- Formulário de contato abre o WhatsApp (19) 99424-1018 com os dados preenchidos.
- `_fonte/` guarda os scripts que geraram as páginas a partir do canvas de design.

Para publicar em qualquer servidor estático, basta copiar o conteúdo desta pasta para a raiz do site.
